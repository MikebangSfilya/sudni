# Судный день — Telegram-бот

Лёгкий Telegram-бот на `aiogram`: читает обычные сообщения в чате, отправляет PNG-циферблат и раз в день пересчитывает индекс по голосам и сигналам из сообщений.

## Команды

- `/clock` — показать текущие часы;
- `/up [1-10]` и `/down [1-10]` — оставить предложение;
- `/vote` — посмотреть текущие предложения.

После `/start` бот покажет инструкцию. Обычные сообщения регистрируют чат и анализируются автоматически.

В конце дня решение принимается при минимум двух уникальных голосах. Берётся среднее предложение участников. Из обычных сообщений бот учитывает только явные формулировки о мобилизации: отрицание снижает индекс, сообщение об объявлении или подготовке повышает. От одного участника учитывается максимум один такой сигнал в сутки. Иногда добавляется прозрачный случайный шум `+1`.

## Запуск

```bash
python3 -m pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN='токен_от_BotFather'
python3 bot.py
```

Проверка без токена:

```bash
python3 bot.py --check
```

По умолчанию ежедневный пост выходит в 09:00 по Москве. Локальное состояние хранится в `state.json`.

Чтобы бот видел все сообщения группы, отключите у него `Privacy Mode` через `@BotFather` командой `/setprivacy` → `Disable`. Иначе Telegram будет передавать ему в основном команды и обращения.

Процент — художественная оценка, а не прогноз, официальная статистика или подтверждение сообщения. Классификация фраз простая и может ошибаться.
