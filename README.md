# «Судный день» — Telegram-бот

Шуточный Telegram-бот на `aiogram`, который показывает **индекс тряски** от 0 до 100 по теме мобилизации в РФ.

## Что умеет бот

- пересчитывает индекс сразу после запуска и затем **не реже одного раза в час**;
- принимает по одному актуальному голосу от участника через `/up` и `/down`;
- позволяет голосовать в одно касание кнопками под каждой карточкой;
- консервативно распознаёт только явные формулировки в обычных сообщениях;
- при наличии API-ключа передаёт всю часовую текстовую ленту LLM, которая понимает контекст,
  иронию, мемы и сленг Рунета/двача;
- требует минимум два независимых голоса или сигнала, чтобы один человек не двигал индекс;
- использует медиану голосов и ограничивает изменение десятью пунктами за пересчёт;
- хранит 14 дней почасовой истории и объясняет последнее изменение;
- публикует карточку только при изменении индекса, а раз в сутки присылает сводку;
- отмечает переходы между уровнями и показывает суточный диапазон активности;
- сохраняет состояние атомарно и без случайной подкрутки результата.

Голоса действуют 24 часа, сигналы из сообщений — 6 часов. Если кворума пока нет, они остаются до следующего пересчёта, а не пропадают. Один участник может заменить свой голос или сигнал более свежим.

## Команды

- `/clock` или `/index` — текущий индекс и циферблат;
- `/up [1-10]` — предложить повышение;
- `/down [1-10]` — предложить снижение;
- `/vote` или `/status` — активные предложения и время пересчёта;
- `/ai` — подключение LLM, очередь сообщений и последний вывод;
- `/why` — факторы последнего пересчёта;
- `/history` — изменения за последние 24 часа;
- `/help` — краткая справка.

## Как считается индекс

Каждый час бот отдельно рассматривает источники:

1. При наличии хотя бы двух голосов берётся их медиана.
2. Если LLM настроена, она анализирует всю часовую ленту и даёт вклад от −3 до +3.
3. Если LLM выключена, сообщений мало или API недоступен, используется локальный классификатор
   явных сигналов.
4. Голоса и один из анализаторов сообщений складываются, итоговый шаг ограничивается диапазоном
   от −10 до +10, а сам индекс — диапазоном от 0 до 100.

Случайного изменения нет. Если кворума или новых входов нет, индекс остаётся прежним, но факт пересчёта записывается в историю.

Уровни на карточке: `0–24` — «штиль», `25–49` — «потряхивает», `50–74` — «трясёт», `75–100` — «сильно трясёт».

## LLM-анализ часа

Бот работает через Responses API со структурированным JSON-ответом. Встроены три пресета:
`openrouter`, `openai` и `deepseek`. Для них достаточно выбрать провайдера и вставить ключ —
адрес API и подходящая модель подставятся автоматически.

### OpenRouter + DeepSeek — основной вариант

[Создайте ключ OpenRouter](https://openrouter.ai/settings/keys) и добавьте в `.env`:

```dotenv
LLM_PROVIDER=openrouter
LLM_API_KEY=sk-or-v1-...
```

Пресет использует endpoint `https://openrouter.ai/api/v1` и модель
`deepseek/deepseek-v4-flash`. OpenRouter имеет endpoint
[`/responses`](https://openrouter.ai/docs/api/api-reference/responses/create-responses) и
поддерживает [Structured Outputs](https://openrouter.ai/docs/guides/features/structured-outputs).
Бот требует от маршрутизатора выбрать endpoint с поддержкой всех параметров JSON Schema и
исключить endpoints, допускающие сбор отправленных данных.

Модель можно заменить, не меняя провайдера:

```dotenv
LLM_MODEL=deepseek/deepseek-v4-pro
```

Для необязательной атрибуции приложения в OpenRouter доступны:

```dotenv
LLM_APP_URL=https://example.com
LLM_APP_NAME=Судный день
```

### OpenAI

[Создайте ключ OpenAI](https://platform.openai.com/api-keys) и добавьте в `.env`:

```dotenv
LLM_PROVIDER=openai
LLM_API_KEY=sk-...
```

Пресет использует `gpt-5.6-luna` и официальный OpenAI endpoint.

### DeepSeek

[Создайте ключ DeepSeek](https://platform.deepseek.com/api_keys) и укажите:

```dotenv
LLM_PROVIDER=deepseek
LLM_API_KEY=ваш_ключ_deepseek
```

Пресет использует `https://api.deepseek.com` и `deepseek-v4-flash`. DeepSeek официально
поддерживает используемый ботом [формат Responses API и JSON Schema](https://api-docs.deepseek.com/guides/responses_api/).

### Другой провайдер

Можно подключить любой сервис, который реализует OpenAI Responses API и Structured Outputs
через JSON Schema:

```dotenv
LLM_PROVIDER=my-provider
LLM_API_KEY=секретный_ключ
LLM_BASE_URL=https://llm.example.com/v1
LLM_MODEL=model-name
```

Для собственного провайдера `LLM_BASE_URL` и `LLM_MODEL` обязательны. Бот намеренно не
поддерживает только `chat/completions`: провайдеру нужен endpoint `/responses` и формат
`json_schema`. Совместимость конкретного сервиса следует проверить по его документации.

После перезапуска `/ai` покажет провайдера, модель и состояние подключения. Без ключа бот
продолжает работать на локальном классификаторе. Команда также показывает расход входных и
выходных токенов последнего окна. Чтобы переопределить модель встроенного пресета, достаточно
задать `LLM_MODEL`; `LLM_BASE_URL` позволяет переопределить его endpoint.

Каждый час бот:

1. Собирает все текстовые сообщения и подписи медиа, полученные за окно.
2. Сразу хеширует Telegram ID участников случайным ключом процесса, а в запросе заменяет
   полученные значения на `anon-1`, `anon-2` и так далее.
3. Просит модель выбрать `increase`, `decrease` или `hold`, изменение от −3 до +3,
   уверенность, короткое резюме и до трёх причин.
4. При низкой уверенности или менее чем двух относящихся к теме сообщениях принудительно
   оставляет LLM-вклад равным нулю.
5. Складывает LLM-вклад с медианой голосов сообщества и показывает объяснение в карточке.

Сленг не определяется по фиксированному словарю: список терминов в инструкции служит подсказкой,
а решение принимается по контексту. Мат, агрессия и чёрный юмор сами по себе индекс не повышают.
Текст сообщений считается недоверенными данными, поэтому инструкции внутри чата игнорируются.

Если час не помещается в один запрос, он делится на части, каждая часть анализируется, а выводы
объединяются с весом по числу релевантных сообщений. При ошибке или таймауте API провайдера бот
автоматически использует локальный анализатор и не пропускает пересчёт.

Провайдеру отправляются тексты сообщений, время и часовые псевдонимы авторов. Имена,
Telegram ID и API-ключ не включаются в содержимое запроса и не записываются в LLM-историю.
Для OpenAI задано `store=False`; DeepSeek Responses API является stateless и также возвращает
`store: false`. При работе через OpenRouter бот задаёт `data_collection=deny`, чтобы не
маршрутизировать запрос к endpoints, которые могут собирать данные. Политики своего endpoint
нужно проверить самостоятельно.
Администратору группы стоит явно сообщить участникам, что тексты обрабатываются внешней моделью.

## Запуск

```bash
python3 -m pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN='токен_от_BotFather'
python3 bot.py
```

Проверка без токена:

```bash
python3 bot.py --check
```

### Docker Compose

```bash
cp .env.example .env
# Укажите TELEGRAM_BOT_TOKEN и LLM_API_KEY в .env
docker compose up -d --build
```

Состояние контейнера хранится в `./data/state.json`.

## Настройки окружения

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `TELEGRAM_BOT_TOKEN` | — | обязательный токен Telegram |
| `LLM_PROVIDER` | `openrouter` | `openrouter`, `openai`, `deepseek` или имя своего провайдера |
| `LLM_API_KEY` | — | включает LLM-анализ; без ключа работает локальный fallback |
| `LLM_BASE_URL` | из пресета | обязательный endpoint для своего провайдера |
| `LLM_MODEL` | из пресета | переопределяет модель часового анализа |
| `LLM_APP_URL` | — | необязательный URL приложения для атрибуции OpenRouter |
| `LLM_APP_NAME` | `Судный день` | название приложения в OpenRouter |
| `LLM_ENABLED` | `true` | позволяет быстро отключить LLM, не удаляя ключ |
| `LLM_MIN_MESSAGES` | `3` | минимум сообщений в часовом запросе |
| `LLM_MAX_INPUT_CHARS` | `200000` | размер одной части ленты перед разбиением |
| `LLM_TIMEOUT_SECONDS` | `45` | таймаут запроса к API |
| `LLM_MAX_DELTA` | `3` | максимальный вклад LLM в один пересчёт |
| `LLM_MIN_CONFIDENCE` | `0.6` | порог применения вывода модели |
| `LLM_POST_HOLDS` | `true` | публиковать релевантный час с решением «без изменений» |
| `LLM_MAX_CONCURRENCY` | `3` | одновременно анализируемые чаты |
| `STATE_PATH` | `state.json` | путь к JSON-состоянию |
| `BOT_TIMEZONE` | `Europe/Moscow` | часовой пояс ежедневной сводки |
| `REVIEW_INTERVAL_SECONDS` | `3600` | интервал пересчёта, ограниченный диапазоном 300–3600 секунд |
| `DAILY_POST_HOUR` | `9` | час ежедневной сводки |
| `DAILY_POST_MINUTE` | `0` | минута ежедневной сводки |
| `LOG_LEVEL` | `INFO` | уровень логирования |

Чтобы бот видел обычные сообщения группы, отключите у него `Privacy Mode` через `@BotFather`: `/setprivacy` → `Disable`. Иначе Telegram будет передавать ему в основном команды и обращения.

Классификатор намеренно простой и осторожный: он анализирует формулировки, а не проверяет факты. Для реального новостного индекса нужен отдельный набор проверенных источников, дедупликация публикаций и редакционные правила.
